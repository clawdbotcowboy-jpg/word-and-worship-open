# Security policy

## Supported software

This repository holds published rules, a public sample of test cases, and a standalone World English Bible verse checker. The Word & Worship application itself is private and is not distributed here.

Please report vulnerabilities in:

- the published tools in this repository (including the verse checker and any scripts that fetch or package WEB data)
- the live Word & Worship service at wordandworship.app, if you believe you have found a security issue there

## How to report

Please use GitHub private vulnerability reporting. On this repository, open the Security tab and choose “Report a vulnerability.” That sends the report privately to the maintainers. Do not email a report, and do not use an unlisted contact address.

Please include:

- a short description of the issue and its impact
- the affected URL, tool, or file, if you know it
- steps to reproduce, or a proof of concept that does not include other people’s data
- whether you have shared the report with anyone else

Do not open a public issue or pull request for a vulnerability. Do not include passwords, session tokens, private keys, or other people’s messages, prayers, journals, or account data in your report.

## What to expect

We will try to acknowledge a valid report. We may ask follow-up questions. Please give us a reasonable chance to investigate and fix the issue before you publish details.

We do not currently offer a bug bounty. Please do not expect a payment for a report.

## Safe harbor

If you act in good faith, avoid privacy violations and service disruption, and report issues privately as described above, we will not pursue legal action for that research. Good faith does not include accessing other people’s accounts or data, phishing, physical attacks, or denial of service.

## Secrets in this repository

This repository must not contain credentials, API keys, private keys, internal hostnames, or unpublished access paths. If you find one, please report it as a security issue.
